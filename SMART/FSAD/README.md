# Smart Campus Event Management System

A centralized platform for managing and discovering campus events, built with Spring Boot, Thymeleaf, and Spring Data JPA.

## Problem Statement
The current event management process in educational institutions often lacks a centralized digital presence, leading to fragmented information, manual administrative burdens, and a lack of real-time insights into student engagement.

For a detailed breakdown, see the [Problem Statement Document](problem_statement.md).

## Key Features
- **Student Portal:** Browse events, register, and track registration history.
- **Admin Dashboard:** Manage event lifecycle (CRUD) and view registration analytics.
- **Real-time Analytics:** Visual representation of event popularity and registration trends.
- **REST API:** Support for programmatic access to event data.

## Technology Stack
- **Backend:** Java, Spring Boot, Spring Data JPA, Spring Security
- **Frontend:** HTML5, CSS3, Thymeleaf, Chart.js
- **Database:** H2 (Development) / MySQL/PostgreSQL (Production)
- **Build Tool:** Maven
